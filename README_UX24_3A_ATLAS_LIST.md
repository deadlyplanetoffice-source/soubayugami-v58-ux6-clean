# UX24.3A Atlas List v1

UX24.2をベースに、Company Atlasのカード前に「一覧管理レイヤー」を追加した差分です。

## 追加内容

- Company Atlas 一覧
- 図鑑検索（コード / 銘柄名 / フォルダ / タグ / メモ断片）
- フォルダ絞り込み
- フォルダ変更
- 星付き固定
- ↑ / ↓ による一覧順序変更
- 一覧から会社図鑑カードへジャンプ
- 図鑑だけに存在する銘柄を「監視+」で監視リストへ戻す導線
- `atlasPrefs` を localStorage と JSON保存/読込に含める

## 設計

フォルダ = 実戦状態、タグ = テーマという前提で、まずはフォルダ管理を軽く入れています。
カード本体や NextActionCard の判定ロジックは原則触っていません。

## 主なフォルダ

- 最優先監視
- 押し目候補
- 強テーマ銘柄
- 決算確認待ち
- 信用需給注意
- 長期候補
- 保留
- 除外・墓場
- 未分類

## 注意

既存の監視リスト順とは別に、Atlas一覧の順序は `atlasPrefs` に保存されます。
JSON保存を行うと、Atlas一覧の星付き・フォルダ・順序もバックアップされます。
