# MDO v58 / UX24.3X

## 目的
直近四半期推移は、通期のような絶対値推移ではなく、YoY%で加速・鈍化を見るべきだった。
UX24.3Xでは、四半期表示を「YoY%チップ列」に変更する。

## 変更点
- アプリ表記を `MDO v58 / UX24.3X` に更新。
- 直近四半期推移は、1期1カード・絶対値カードをやめる。
- 表示を以下の3行に固定。
  - 売上YoY
  - 営利YoY
  - 利益率
- 各行は左から右へ古い→新しい順でチップ表示。
- 直近チップだけ強調。
- プラスは緑、マイナスは赤、利益率はシアン系。
- 絶対値は初期表示しない。
- 元表は「四半期の元表を見る」に退避。
- 通期カードと市場期待差はUX24.3Wを維持。
