# MDO v58 / UX24.3K

UX24.3J のレトロSF配色を少し強め、Atlas List に「保有」タグ/フォルダを追加した版。

## 変更点

- アプリ表記を `MDO v58 / UX24.3K` に更新
- Atlas List の既定フォルダに「保有」を追加
- 図鑑メモに「保有中 / 現物 / 信用保有 / 平均取得 / 取得単価 / 買値」などが含まれる場合、初期分類を「保有」に寄せる
- Atlasタグの色分けを整理
  - 保有：アンバー/金
  - 最優先監視：マゼンタ/赤
  - 強テーマ銘柄：シアン
  - 押し目候補：グリーン
  - 決算確認待ち：黄色
  - 信用需給注意：紫
  - 長期候補：青
  - 保留/未分類：グレー
  - 除外・墓場：暗いグレー
- レトロSF感を強めるため、背景グリッド、ネオン境界線、カード発光を少し強調

## 注意

「保有」は売買助言ではなく、Atlas List 上で自分の保有銘柄を整理するためのタグ/フォルダです。
