# MDO v58 / UX24.3V

## 目的
業績推移ページの「直近四半期推移」と「市場期待差」が長文・生テキスト中心で見づらかったため、モバイル用の比較カードUIへ変更する。

## 変更点
- アプリ表記を `MDO v58 / UX24.3V` に更新。
- 直近四半期推移を、1四半期1カードの表示へ変更。
  - 四半期
  - 売上高
  - 営業利益
  - 営業利益率
  - 売上YoY
  - 営業利益YoY
- 四半期カードをタップすると、経常/税前・純利益などの詳細を展開。
- 直近四半期推移の冒頭に一行要約を追加。
- 市場期待差を3ブロック化。
  - 判定
  - 会社予想
  - 市場期待
- 市場期待差の長文は「詳細本文を開く」に格納。
- UX24.3Uまでの内容は維持。
