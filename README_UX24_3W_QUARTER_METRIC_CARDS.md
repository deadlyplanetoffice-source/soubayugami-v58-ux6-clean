# MDO v58 / UX24.3W

## 目的
UX24.3Vの直近四半期推移は「1四半期1カード」になっていたが、見たいのは四半期単体ではなく、売上・営業利益・利益率など各項目の推移だった。
UX24.3Wでは、直近四半期推移も通期業績と同じ「項目別ミニ推移カード」に統一する。

## 変更点
- アプリ表記を `MDO v58 / UX24.3W` に更新。
- 直近四半期推移を、通期業績と同じ項目別ミニ推移カードに変更。
  - 売上高
  - 営業利益
  - 経常/税前
  - 純利益
  - 営業利益率
  - 売上YoY
  - 営業利益YoY
- 市場期待差も、箇条書きの大きなカードから、ミニ推移カード風の3カードへ整理。
  - 判定
  - 会社予想
  - 市場期待
- UX24.3Vまでの内容は維持。
