# MDO v58 / UX24.3U

## 目的
フィックスターズの業績カードで、EPS・配当・自己資本比率が列ズレして表示される問題を修正する。

## 原因
貼り付け本文がMarkdown表ではなく空白区切り表として抽出された場合、
`2026/9 会社予想 10,800 ...` の `会社予想` が1セルとして扱われ、以降の列が1つずつズレていた。

## 変更点
- アプリ表記を `MDO v58 / UX24.3U` に更新。
- 空白区切り業績表の行補正を追加。
- 期の直後にある `会社予想 / 会社計画 / 四季報 / コンセンサス` などを除去。
- `※2Q時点` や説明文が行末に連結された場合は切り落とす。
- 説明文を業績行へ連結しにくくした。
- UX24.3Tまでの内容は維持。
