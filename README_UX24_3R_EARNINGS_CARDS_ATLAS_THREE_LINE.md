# MDO v58 / UX24.3R

## 目的
UX24.3Qで版名を分けたが、業績推移スマホカード化が反映されたベースではなかったため、業績ページが横表のまま残っていた。
UX24.3Rでは、業績スマホカード化とAtlas List 3段表示を統合する。

## 変更点
- アプリ表記を `MDO v58 / UX24.3R` に更新。
- 業績推移ページは、UX24.3P mobile cards のスマホカード表示を維持。
- Atlas List上部カードを3段構成に変更。
  1. 銘柄名
  2. コード / 株価 / 前日比
  3. フォルダ / タグ / 業績あり / 並び替え
- Atlas List 2層目に `業績推移` ボタンを追加。
- PC版の本格修正は保留。

## 確認点
- フィックスターズなど長い銘柄名で、コード/価格/タグ/上下ボタンが重ならないか。
- 2層目から業績推移へ直接移動できるか。
- 業績ページが横表ではなくスマホカード中心になっているか。
