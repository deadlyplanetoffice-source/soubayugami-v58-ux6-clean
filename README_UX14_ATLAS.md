# 相場歪観測機 v58 UX14 — 動く銘柄図鑑

UX14は、iPhone版を「スキャナー」中心から「動く銘柄図鑑」中心へ寄せた版です。

## 主な変更

- 表示名を `相場歪観測機 v58 UX14` に変更
- 下部タブを `マイ図鑑 / 探索 / 調べる / 保存` に変更
- 銘柄詳細の先頭を「図鑑カード」化
- 図鑑完成度を `★★★★★` で表示
- 会社の核、直近の歪み、図鑑完成度チェックを結論画面に表示
- スキャナーカードにも図鑑完成度・未記録項目を表示
- 「会社調査貼り付け」を「図鑑に書き込む」へ寄せた表現に変更
- 「信用需給」は「信用需給を記録する」として図鑑記録の一部に変更

## 反映方法

GitHubにこのZIPの中身を上書きアップロードし、Renderで `Clear build cache & deploy` を実行してください。

確認URL例:

```txt
https://あなたのRender名.onrender.com/?ux14=1
```
