# MDO v58 / UX24.3M Earnings Trend Page v1

## 目的
業績推移は外部自動取得ではなく、会社調査・信用調査と同じく「自分で調べて貼り付ける」導線にする。

## 追加内容
- 「業績」タブに業績推移ページを追加
- 業績調査プロンプトを自動生成
- プロンプトをコピー可能
- 調査結果貼り付け欄を追加
- 貼り付け本文を銘柄別に保存
- 【MDO保存用サマリー】または見出しから以下を抽出
  - 業績位置
  - 進捗評価
  - 市場期待差
  - 次回決算の注目数字
  - 業績は壊れているか
  - 押し目判断に使えるか
  - 未確認事項
- Atlas List 2層目に「業績メモあり」を表示
- JSON保存/読込に `earningsTrendNotes` を追加

## 方針
- 自動取得はしない
- 業績数字の推移に集中し、会社概要・信用需給・ニュース反応とは分離
- 表の完全構造化は次段階。今回は見出し抽出型
