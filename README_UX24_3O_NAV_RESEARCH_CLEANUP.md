# MDO v58 / UX24.3O

## 目的
UX24.3Nで増えすぎた調査系導線と表示注釈を整理し、判定・図鑑・記録調査の役割を分け直した版。

## 変更
- アプリ表記を `MDO v58 / UX24.3O` に更新
- JPXβボタンを削除
- 常時表示の仕様注釈を削除
- Atlas List 2層目の導線を `判定 / 図鑑 / 記録調査 / チャート` に整理
- モバイル詳細タブから業績単独タブを外し、`記録調査` 内の詳細一覧へ移動
- 記録調査内を `会社調査 / 信用需給 / 業績推移 / 急落理由 / IRニュース / 価格指標` に整理
- 会社調査のプロンプト・App・抽出・図鑑Pボタンを一列化
- 信用/業績の調査ボタン配置に寄せた

## 未達リスト追加
- 判定精度問題：自動取得ベースの判定と、会社/信用/業績調査結果の補助レイヤーの反映方法を検証する。
- 調査結果で判定そのものを上書きせず、まずは判定画面に「根拠補助」として並べる方向。
