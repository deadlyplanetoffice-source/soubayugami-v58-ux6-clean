# MDO v58 / UX24.3Q Atlas Three-Line Mobile Card

## 目的
- Atlas List のカード下段で、価格・タグ・移動ボタンが重なって見える問題を解消する。
- iPhone 上で一見して読めるように、カード上部を 3 段構成へ整理する。
- 版名の重複を避けるため、今回の版を `UX24.3Q` にリネームする。

## 変更点
- アプリ表記を `MDO v58 / UX24.3Q` に更新。
- Atlas List のカード上部を以下の 3 段に再編。
  1. 銘柄名
  2. コード / 株価 / 前日比
  3. フォルダ / タグ / 業績あり / 並び替えボタン
- 下段の文字サイズを揃え、タグと上下移動ボタンの重なりを回避。
- 並び替えボタンは 3 段目右端に固定。

## 方針
- PC 版の大改修は行わず、今回はモバイルの Atlas List の読みやすさを優先。
- 既存のフォルダ / タグ / 展開導線は維持。
