# MDO v58 / UX24.3P Earnings Table View

## 目的
UX24.3N/3O の業績推移ページでは、貼り付け本文が長文・数字の塊として表示され、iPhone上で推移が一見して読みにくかった。
UX24.3Pでは、業績推移ページを「数字の変化が表で見える」方向へ修正した。

## 変更点
- ヘッダーを `MDO v58 / UX24.3P` に更新。
- 業績ページの上部に4項目のミニサマリーを追加。
  - 業績位置
  - 進捗評価
  - 市場期待差
  - 次回注目
- 通期業績・四半期推移をアコーディオン表示に変更。
- Markdown表がある場合は表として表示。
- Markdown表がない場合も、空白区切りの業績行を簡易テーブル化する補助パーサーを追加。
- 通期・四半期の表は、項目を縦軸、期を横軸にした比較マトリクスで表示。
- 変化方向を `↗ / → / ↘` で表示。
- 進捗率・市場期待差は初期状態では折りたたみ。
- 長文説明は表の下へ逃がし、初期表示では数字比較を優先。

## 方針
- 自動取得はしない。
- 貼り付け本文からの抽出・整形に限定。
- 会社調査・信用調査とは役割を分け、業績推移ページでは数字の推移を最優先する。
