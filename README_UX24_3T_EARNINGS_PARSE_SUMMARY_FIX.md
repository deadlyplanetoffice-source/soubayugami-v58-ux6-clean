# MDO v58 / UX24.3T

## 目的
フィックスターズ等の業績推移で、配当などのカード値が不自然になる問題を修正する。
また、サマリー文章が途中で切れて全文を確認できない問題を改善する。

## 変更点
- アプリ表記を `MDO v58 / UX24.3T` に更新。
- 業績表が `項目 / 2023 / 2024 / 2025 / 予想` の横持ち形式だった場合、行ごとにカード化する処理を追加。
- 配当、EPS、営業利益率、自己資本比率などの列ズレを抑制。
- `会社予想` などの文字が数値列に混ざった場合、カード表示では除去。
- 業績サマリーの長文は初期表示で短くし、タップで全文展開できるように変更。
- UX24.3Sまでの変更、業績スマホカード化、Atlas List 3段表示、2層目の業績推移ボタンは維持。
